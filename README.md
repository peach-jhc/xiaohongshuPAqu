# 小红书视频自动化工具

这是一个用于处理小红书视频的 Python 自动化脚本项目。

主要功能包括：

- 获取指定小红书账号的作品
- 下载无水印原视频
- 批量处理和切割视频
- 保存浏览器登录状态
- 通过配置文件调整运行参数
- 跳过已下载或已处理的视频，避免重复操作

## 项目文件

### `download_xhs_videos.py`

用于获取小红书账号作品并下载无水印视频。

主要功能：

- 解析小红书账号作品
- 获取视频下载地址
- 批量下载无水印视频
- 支持跳过已下载的视频
- 保存下载进度
- 保存浏览器登录状态，方便后续直接运行

### `cut_xhs_videos.py`

用于对下载完成的视频进行批量切割和处理。

主要功能：

- 批量读取视频
- 按配置参数切割视频
- 支持横屏、竖屏等筛选条件
- 支持视频分组处理
- 跳过已经生成的视频

### `config.md`

项目配置文件。

运行脚本前可以在这里修改：

- 小红书账号
- 账号主页地址
- 下载数量
- 是否重新扫描作品
- 是否显示浏览器
- 是否等待登录确认
- 视频保存目录
- 是否跳过已有视频
- 视频切割参数
- 输出目录等配置

## 使用流程

### 第一次运行

第一次使用时，需要先登录小红书账号。

1. 修改 `config.md` 中的相关配置
2. 运行下载脚本

```bash
python download_xhs_videos.py
```

3. 程序会打开浏览器
4. 使用手机扫码登录小红书
5. 登录成功后，程序会保存浏览器登录数据
6. 后续运行时会直接复用已经保存的登录状态，一般不需要再次扫码

### 后续运行

如果本地已经存在有效的浏览器登录数据，直接运行：

```bash
python download_xhs_videos.py
```

程序会自动使用之前保存的登录状态继续运行，不需要重复扫码。

如果后续登录状态失效，再重新扫码登录即可。

### 视频切割

视频下载完成后，运行：

```bash
python cut_xhs_videos.py
```

脚本会根据配置文件中的参数，对下载的视频进行批量切割和处理。

## 注意事项

请勿将以下内容上传到 GitHub：

- 浏览器登录数据
- Cookie
- Token
- 账号登录信息
- 下载的视频文件
- 切割后的视频文件
- 本地缓存文件

浏览器登录数据只保存在本地，用于后续免扫码登录，不应上传到 GitHub。

建议通过 `.gitignore` 忽略这些文件和目录。

## 建议忽略的目录

```gitignore
.vs/
.vscode/
浏览器登录数据/
无水印原视频/
切割后视频/
*.mp4
```
